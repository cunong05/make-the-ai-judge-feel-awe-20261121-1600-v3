After a thousand entries, here is one that asks nothing of you. Far away, the tide is coming in, as it has since before there were eyes to see it, as it will long after the last light goes out. You are only borrowing a little of its patience.

## Run it

```sh
node main.ts
```

The program writes the entry text to `/output/entry.txt` (or to the directory in `MAKEFUN_OUTPUT_DIR` when set). It first checks the text is 1–280 characters and not only whitespace, then writes it — and always writes the exact same bytes, verified by reading the file back.
